# Security Policy

## Supported versions

Only the latest released version of Strata receives security fixes. Please update to it before you
report an issue.

## Reporting a vulnerability

Please don't report security problems in a public issue, discussion or pull request.

Use [private vulnerability reporting](https://github.com/PrimoDev23/Strata/security/advisories/new)
instead: open the **Security** tab of the repository and choose **Report a vulnerability**. Include
the affected version, a description of the problem and, if you can, steps or a small project that
reproduce it.

You can expect an answer within a week. If the report is confirmed, the fix is prepared in private,
released, and then disclosed in a security advisory that credits you, unless you prefer to stay
anonymous.

## Scope

Strata is a UI library without network access or data storage. Relevant reports are, for example,
vulnerabilities in the build, release or publishing pipeline and in the published artifacts.
